## 2. Findings

Evidence coordinates are frame x in CSS px at a 1200px window unless stated. "C" is the content
column's left padding edge; body text sits at C+6.

### P0: broken

<a id="f01"></a>**F01 Headings lose their style in long documents.** Area: headings, outline gutter.
Evidence: in the gallery, every heading from `## Toggles` down renders at 21px with no
`cm-md-heading-line` class, while earlier H2s are 29.4px (`ui-review-2026-11-12/dump-light-1200.json`;
screenshots `gallery-light-1200-09.png` to `-11.png`). Cause (committed code, not WIP):
`headingLineDecorationField` in `headingGutterSync.ts` rebuilds only when the text changes, but
CodeMirror parses long files in the background, so headings parsed after opening never get the class
until an edit. Fix: also rebuild when the syntax tree changes (`syntaxTree(tr.startState) !==
syntaxTree(tr.state)`). Risk low (same function, more often). Effort S.

<a id="f02"></a>**F02 Cmd/Ctrl+F types into the document.** Area: search. Evidence: after Cmd+F the
search box opens but `document.activeElement` is still `.cm-content`; typing "words" and saving gave
`Second paragraph with words.words` at both HEAD and WIP (`followup-WIP.json`, `followup-HEAD.json`;
`st-light-search.png`). Fix: focus and select the search input when the overlay opens from the
shortcut. Risk low. Effort S.

<a id="f03"></a>**F03 `/` menu hidden under the toolbar.** Area: slash menu. Evidence: with the caret in
the lower half of the window the menu flips upward; its top is at frame y=0, under the 60px formatting
toolbar, so "Bulleted List" and "Callout" are covered (`st-light-slash-menu.png`; menu 444px tall,
16 rows of 34px, viewport 777px). Fix: give the autocomplete tooltip the space below the toolbar
(CodeMirror `tooltips({ tooltipSpace })`) and cap its height to that space with internal scroll.
Risk low. Effort S.

<a id="f04"></a>**F04 Dark-theme selection is unreadable.** Area: selection, theme. Evidence: focused
selection background is `rgb(215,212,240)` behind text `rgb(204,204,204)`, about 1.1:1, in Dark Modern
and Abyss (`states-dark.json`, `st-dark-selection.png`). Cause: CodeMirror's built-in light selection
rule wins because the editor theme is never marked dark. Fix: create the theme with `{ dark: true }`
for dark VS Code themes, or raise the selection rule's specificity and use
`--vscode-editor-selectionBackground`. Risk low. Effort S.

### P1: clearly off

<a id="f05"></a>**F05 Alt-text bar under every image.** Area: images. Evidence: "Local icon" and
"Wide image" grey bars under loaded images (`gallery-light-1200-08.png`, `-09.png`). Cause:
`.cm-md-image-placeholder { display: block }` (cm6Theme.ts) overrides the `hidden` attribute that
`syncImageElement` sets after load. Also: the broken image shows the browser's broken-picture glyph
plus a grey bar, not the red error style. Fix: `.cm-md-image-placeholder[hidden] { display: none }`,
then check the error path. Risk low. Effort S.

<a id="f06"></a>**F06 Scroll jumps at every table.** Area: tables, scroll. Evidence: scrolling the
5,000-line file gives a layout-shift score of 0.34 to 0.41 (good is under 0.1). Every source is the
same: when a table enters the viewport, it and everything after it move up 8px (`followup-WIP.json`:
`cm-md-table-widget dy=-8` x98, one per table). Cause: the table's 8px bottom margin sits outside the
box CodeMirror measures. Fix: padding instead of margin inside the widget. Risk low. Effort S.

<a id="f07"></a>**F07 First toggle shifts the document.** Area: layout, toggles. Evidence: `.cm-content`
left padding is 16px, and 40px once a document has a toggle (`.cm-md-has-toggles`). Same window, card
edge at x=137 without toggles (`blocks-WIP.png`) and 161 with (`gallery-light-1200-00.png`). Typing
`> ` for the first toggle moves every line 24px. Related: without toggles, the outline rail overlaps
the YAML card labels at narrow widths (`probe-dark-700.png`). Options: (a) always reserve 40px
(recommended: stable, and also clears the rail), (b) let the hover handle overlap the margin. Risk low.
Effort S.

<a id="f08"></a>**F08 Uneven vertical rhythm.** Area: all blocks. Evidence: between every block pair
the source has exactly one blank line (25.5px, measured for 80 pairs; `rhythm-gallery-light-1200.json`),
but blocks carry hidden space inside, so the visible gaps differ:

| Block | Visible space it adds | Cause |
|---|---|---|
| YAML card to text | 79px gap vs 25.5px between paragraphs | 40px `.yaml-frontmatter-tail-spacer` |
| Code card | about 57px above and below | 32px `--cm-md-fence-external-gap` each side |
| One-line callout | 84px tall box for one 25.5px line | hidden `:::` lines still render 25.5px each |
| Image | +32px each side, +32px more when the image loads | widget padding plus `.md-image` margin |
| Horizontal rule | 45.6px above, 56px below | rule is the top border of a 13px box |
| Table | 33.5px after vs 25.5px elsewhere | 8px margin (also F06) |

Fix: one block gap everywhere (the blank line), inner padding of 8 to 12px for cards, centre the HR.
Risk medium (CodeMirror's height map; each change needs a geometry test). Effort M.

<a id="f09"></a>**F09 Card edges sit 6px left of text.** Area: alignment. Evidence: body and headings
at C+6 at all three widths; card edges (YAML, code, callout, table, Mermaid, image) at C; text inside
cards at C+7 (code, table), C+13 (YAML), C+36 (callout first line, C+16 on later lines), quote text at
C+14. Cause: CodeMirror's `.cm-line { padding-left: 6px }` applies to text lines, not to block widgets.
Options: (a) card edge on the text column (C+6) with a 12px inner inset (recommended; reads like
Notion), (b) keep cards out-dented but put card text on the text column. Needs a decision with
before/after shots. Risk medium. Effort M.

<a id="f10"></a>**F10 Lists use a different indent step from toggles.** Area: lists, toggles.
Evidence: list text at C+24.4, +48.8, +73.2 (3 monospace characters per level, fractional), toggle body
at +20, +40. Measured relative to body text: list text +18.4, toggle body +20. mdWebview.css also
overrides the theme's marker margins (4px / 6px), so `--list-marker-inset` never applies. Fix: one
20px step for lists, toggles and quotes. Risk medium (hanging indent and click positioning have many
tests). Effort M.

<a id="f11"></a>**F11 Code fences show raw markers.** Area: code. Evidence: ```` ```ts ```` and ```` ``` ````
are always visible, and there is no language label (`blocks-HEAD.png`, same at WIP). Committed design,
not a regression. Options: (a) hide fence lines when the caret is outside and show the language in the
chrome bar (recommended, Notion-like), (b) keep as is. Decision needed. Risk medium. Effort M.

<a id="f12"></a>**F12 `/` menu order and a wrong hint.** Area: slash menu. Evidence: menu lists
Bulleted List, Callout, Divider, Heading 1... (alphabetical), while `SLASH_OPTIONS` is ordered Text,
H1 to H4, lists, Callout, Toggle... Quote and Toggle both show `>`, but typing `> ` makes a toggle; the
quote shortcut is `"`. Fix: give options a descending `boost` so CodeMirror keeps the curated order;
change the Quote hint to `"`. Risk low. Effort S.

<a id="f13"></a>**F13 Mermaid error is a dead end.** Area: Mermaid. Evidence: the card's message tells you to
switch to Code to edit, but the card shows no controls, even on hover
(`st-light-hover-mermaid-error.png`). Clicking the card was not tested. Fix: show the Diagram/Code
switch on error cards, error colour and icon. Risk low. Effort S.

<a id="f15"></a>**F15 Formatting toolbar clips at narrow widths.** Area: toolbar. Evidence: at a 600px
window the second row cuts an icon in half at the right edge, with no overflow menu
(`gallery-light-600-00.png`). Fix: wrap, or an overflow "more" menu. Risk low. Effort M.

<a id="f16"></a>**F16 Toolbar text icons fail contrast.** Area: toolbar, a11y. Evidence: H1, H2, H3,
AB, ab, Ab are text at 11px with 3.62:1 in light (needs 4.5:1); SVG icons 3.62:1 pass the 3:1 UI rule
(`states-light.json`). Dark is 4.55:1. Fix: a darker muted-icon token in light themes. Risk low.
Effort S.

## 3. Systemic issues

| Issue | Evidence | Impact |
|---|---|---|
| Two left edges by construction | Text lines get CodeMirror's 6px padding; block widgets do not | Every card is 6px out-dented (F09); fixing per block will regress |
| No real spacing scale | About 90 off-grid values (menus `7px 10px`, fence 6px, cells 6px, YAML 10/12px, outline 10px step, list 24.4px); `--space-1..5` exist but are used 0 times in the editor CSS | Nothing snaps to the 4px grid; 25.5px base line height is fractional |

| Hard-coded colours | Selection `#d7d4f0` (F04), toast `#1e1e20`, spell squiggle `#e51400`, `rgba` shadows, feedback button `#fff` | Break in dark and high contrast |
| Typography sprawl | Six small sizes (10, 11, 12, 12.75, 13, 13.5px), eight line-heights; two look-alike menus at 13px and 12px | Chrome feels slightly inconsistent |
| Block spacing hidden in widgets | F08 table | Blank lines look unequal |
